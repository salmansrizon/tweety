# Tweety — Glossary

> This file is a glossary only. No implementation details, no specs, no scratch notes.

---

## Terms

**Tweety**
The canonical product name. A zero-cost serverless multi-platform scraper and RAG archive CMS. Previously referred to as "TopicRadar" in early docs — that name is retired.

**Repo layout (monorepo)**
A single repository with two top-level directories: `/etl/` (Python ETL pipeline) and `/web/` (Next.js 14 CMS). GitHub Actions workflows live at `.github/workflows/`. Shared config and docs at the root.


**Topic**
A user-defined subject of interest (e.g., "AI Agents", "Rust Lang"). The top-level unit of configuration. A Topic groups one or more Creators and one or more Platforms.

**Creator**
A platform-specific source account or community assigned to a Topic. A Creator is either a Twitter handle (e.g., `@sama`) or a Reddit subreddit (e.g., `r/LocalLLaMA`).

**Platform**
One of the two supported data sources: `twitter` or `reddit`.

**Post**
A single piece of original content scraped from a Platform — a Tweet or a Reddit post. Retweets and cross-posts are excluded.

**Post Limit**
Maximum **10 Posts per Creator per day**, per Platform. Applied at scrape time (Reddit: fetch top 10 from 24h; Twitter: stop scrolling after 10 qualifying original posts). Caps Gemini embedding calls and storage growth predictably.

**Engagement Score**
A computed, cross-platform numeric score used to rank Posts. Calculated differently per Platform (see PRD §5.2).

**ETL Pipeline**
The automated daily batch job running on GitHub Actions that fetches config, scrapes Posts, scores them, generates Embeddings, and writes to both storage layers. Hard cap: 25 minutes per run (`timeout-minutes: 25`).

**ETL Schedule**
Cron: `0 1 * * *` — runs at 01:00 UTC (07:00 BST) every day. Scrapes the previous 24 hours of Posts.

**Embedding**
A 768-dimension vector representation of a Post's normalized text, generated by Google Gemini `text-embedding-004`.

**RAG**
Retrieval-Augmented Generation. The question-answering pipeline: a user query is embedded, semantically matched against stored Post vectors, and passed with retrieved context to an LLM for synthesis.

**LLM Router**
The OpenRouter free model router endpoint used for all LLM generation in Tweety. No specific model is hard-coded — OpenRouter selects an available free model automatically. Configured via `baseURL: https://openrouter.ai/api/v1` with `model: openrouter/auto`.

**Archive**
The full historical store of scraped Posts. Raw metrics live in BigQuery; semantic vectors live in Supabase `post_vectors`.

**Archive Horizon**
The maximum lookback window for the Archive: **30 days**, chosen by the user. Both BigQuery and Supabase `post_vectors` are pruned to 30 days at the end of every ETL run. The CMS date picker disables dates older than 30 days. Posts beyond the horizon are not recoverable.

**Retention Window**
The configurable period for which Posts are kept across all storage layers. Currently set to **30 days** for all Platforms. Pruning runs at the end of every ETL Pipeline execution.

**Supabase Auto-Pause**
Supabase free tier pauses the database after 7 days of inactivity. The daily ETL run acts as the keep-alive under normal operation. If the ETL is skipped for 7+ consecutive days, the user must manually un-pause via the Supabase dashboard before the next run. No automated keep-alive job is used.

**Cookie Expiry Alert**
The event triggered when Playwright detects a Twitter login wall (cookie expiration). The ETL aborts the Twitter scraping phase, logs `last_run_status = "Twitter Cookie Expired"` to Supabase `app_settings` and writes to the ETL Log Table, and emits a GitHub Actions email notification. Reddit scraping continues unaffected.

**ETL Log Table**
The `etl_runs` table in Supabase used to log the history, execution times, success status, scraped counts, and errors of daily ETL Pipeline runs. It is used to surface a status panel in the CMS and to render warnings on days with Reddit-Only Mode.

**Playwright Stealth**
The anti-bot hardening suite used in the ETL Pipeline to bypass detection. Includes UA rotation, randomized viewports, delays between scrolls, and standard stealth finger-print patching.

**Reddit-Only Mode**
A degraded but valid ETL run state: Twitter scraping was skipped (due to timeout or Cookie Expiry Alert), Reddit completed successfully. Logged to `app_settings.last_run_status` and `etl_runs`. Not an error — the Archive simply has no Twitter Posts for that day.

**CMS**
The Next.js web portal. The user interface for configuring Topics, Creators, and credentials, and for browsing the Archive and querying via RAG Chat.
